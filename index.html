Где сейчас ваши товары: на отгрузке, в пути, на приёмке или уже на складе. Неофициальный инструмент для продавцов Ozon.

Ключ уходит только на api-seller.ozon.ru — прямо из вашего браузера. У страницы нет сервера и она больше никуда ничего не отправляет: это закреплено политикой безопасности в самом файле. Создайте ключ с правами только на чтение, например роль «Admin read only». Подробности — в README.
Неофициальный инструмент, не связан с Ozon. Название Ozon принадлежит его владельцу.

Будет один zip: по файлу на каждый кластер в формате шаблона Ozon «артикул / имя (необязательно) / количество», колонка имени пустая (только строки с количеством больше 0) и сводный отчёт. Это файлы для вашей загрузки: проверяйте их перед загрузкой в Ozon, инструмент сам ничего в Ozon не отправляет.
План строится по кластерам, а не по складам: склад внутри кластера Ozon назначает сам при выборе таймслота поставки. Формула: к отправке = max(0, округлить вверх(продажи в день × дней × (1 + запас)) − остаток − в пути), затем округление вверх до кратности упаковки. Значок рядом с названием поля объясняет, что оно значит.
